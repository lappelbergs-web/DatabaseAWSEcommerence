# CloudStore

CloudStore is a simplified e-commerce application built with Java and Spring Boot. The project focuses on building, testing, containerizing, and deploying a cloud-based application using modern DevOps principles.

## Features

- User registration and login
- Password hashing with Spring Security
- Product listing from FakeStore API
- Product detail page
- Shopping cart
- Checkout
- Order confirmation
- Order history for logged-in users
- Swagger/OpenAPI endpoint testing

## Tech Stack

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- Thymeleaf
- MySQL
- Docker
- Docker Compose
- GitHub Actions
- Docker Hub
- AWS RDS
- AWS EC2
